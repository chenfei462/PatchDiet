# agent-large-pr

Reproducible local fixture for the hackathon judge pack.

The scenario simulates an AI coding agent that completed a small cart pricing
change but also committed bulky planning notes and generated output. It is a
local fixture, not a public market-result claim.

Run it through the benchmark harness:

```bash
npm run bench:examples
```

Then inspect:

```bash
.patchdiet/example-benchmarks/agent-large-pr/report.md
```
