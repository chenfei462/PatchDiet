02GATES

Configured-check pipeline Candidate by candidate

A removal only counts when the gate stays green.

Each candidate is evaluated away from the working branch. Passing configured checks supports the removal; a failure keeps the code and records the boundary.

BOUNDARY / WEAK TESTS

The gate is only as strong as the configured checks.

A green suite is useful evidence, not a guarantee that behavior is unchanged. Weak or incomplete tests can miss regressions.

PatchDiet proves
The configured checks still pass after the candidate removal.
PatchDiet does not prove
Semantic equivalence, complete coverage, or production correctness.

05HANDOFF

Local workflow Proof before merge

Put the diff on a diet. Keep human review in the loop.

Install locally, build the CLI, and shrink against the checks your repository already trusts. PatchDiet reduces the surface; human review decides what ships.

Open the PatchDiet demo

$ npm run build
