# Pricing Draft

PatchDiet should price verified cleanup runs, private repo coverage, retained history, and managed runner minutes. It should not price by AI review comments because PatchDiet is not a reviewer bot.

## Free

- Public repositories.
- Local CLI.
- GitHub Action.
- GitHub App preview.
- Local reports and Diet Cards.

## Team

- Private repositories.
- Managed verified runs.
- PR shrink history.
- Badge hosting.
- Basic team metrics.

## Business

- Organization policy controls.
- Audit logs.
- SSO/SAML.
- Retention controls.
- Self-hosted runner support.

This is a planning draft only. Billing, checkout, account management, and terms require external product and legal setup.
