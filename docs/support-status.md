# Support And Status

PatchDiet can be launched responsibly only if users know where to ask for help and whether the hosted surface is healthy.

## Support Entry

- Support email: `support@your-domain.example`
- Support page: link from the Marketplace listing and README
- Security reports: GitHub private vulnerability reporting when available, otherwise `SECURITY.md`

## Status Page

- Hosted App status page: public URL on the chosen status provider
- Scope: preview webhooks, verified jobs, artifact delivery, and API availability
- Update policy: incident, degraded, and resolved states with timestamps

## Domain And Hosting

- Pick a domain for the hosted App and support pages
- Configure HTTPS and a stable webhook URL
- Store GitHub App secrets outside the repository

## Launch Handoff

1. Register the domain with the hosting provider.
2. Create the support mailbox.
3. Publish the status page URL.
4. Link both URLs from the README and Marketplace listing.
5. Verify the webhook health check and preview comment flow against the hosted App.
