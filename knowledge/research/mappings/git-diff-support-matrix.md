Current implementation evidence is from `packages/core/src/diff.ts`, `packages/core/src/git.ts`, `packages/core/src/patch-encoder.ts`, and the P0-2 fidelity tests. A support status describes the current PatchDiet path; it does not claim full Git compatibility.

## PD-R158 final evidence audit (2026-10-27)

Existing rows and runtime support decisions above are preserved. Per-row normative references were added after re-reading the manuals. A dedicated dissimilarity-header round-trip assertion closes the explicit parser/serializer gap; it does not establish end-to-end rewrite application. No runtime implementation changed.

Test references in `tests/e2e/shrink-p0-2-fidelity.test.ts` (line numbers at audit):

- [F134]: line 134, whole new-file reverse deletion.
- [F173]: line 173, byte-exact round trip and application on the base tree.
- [F232]: line 232, mode-only and mode+content human review/whole-file retention.
- [F274]: line 274, symlink/gitlink whole-file human review and base application.
- [F307]: line 307, new-file candidate failure prevents per-hunk removal.

Implementation locators: `packages/core/src/diff.ts` (`parseUnifiedDiff`, `serializeUnifiedDiff`, `detectUnsupportedDiffForms`, `isKnownExtendedHeader`); `packages/core/src/shrink.ts` (whole-file/metadata policies and required final checks); `packages/core/src/git.ts` (Git application). These tests establish bounded cases, not exhaustive compatibility. Final verification is mandatory on supported paths; an unsupported combined diff remains unverified human-review input. Missing combinations in the matrix remain explicit.

Additional normative source records: `standard:git-config-quotepath` / `claim:git:004` and `standard:git-fast-import` / `claim:git:005`. `core.quotePath` and `filemodify` were independently read from the official Git manual on 2026-10-27.
